# Shared Firebase backend

The canonical deployable backend for both GOOTE web and Android is this repository's `functions/` package, Firebase project `goote-f48d8`, region `us-central1`, Node.js 22.

The separate `GOOTEAPP` repository (`../goote_app`) owns the Flutter Android app. Its `backend/` is local planning/scaffolding code, not an independent Firebase deployment source. Make shared callable/API changes here and validate both clients before deployment. The `mobile/` scaffold in this web checkout is not the canonical Android release project.

`functions/shared-contract.json` records the currently supported function names. `tests/backend-contract.spec.ts` prevents accidentally removing deployed exports. Web SSR is generated by Firebase Hosting and uses its own runtime; do not add its generated function to the shared Functions codebase.

Release gates: Functions build and lint, root build and lint, Playwright tests, and verification of mobile callable names. Do not delete existing functions or replace the backend with an older web-only source snapshot.
